# TicTac Tetris — User Manual

## Requirements

* Python
* uv
* Pygame

## Installation

Clone the project and navigate to the project folder.

```bash
uv venv
uv add pygame
```

## Running the Game

Run the game with:

```bash
uv run src/tetris.py
```

## Alternative

Alternatively you can run the script provided while inside the project directory

```
./run_uv.sh
```

## How to Play

* Use the keyboard to move the current piece.
* Move and rotate pieces to fit them into the board.
* Complete horizontal lines to clear them and earn points.
* Continue placing pieces until the game ends.

## Current Version

This manual covers the **current base version of TicTac Tetris**. Additional features such as Challenges, Mission Mode, UI improvements, and Quality-of-Life updates will be documented as they are implemented.
